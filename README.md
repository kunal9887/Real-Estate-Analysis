⚡ Real Estate Property Analytics Dashboard

Project Title – Real Estate Property Market Overview & Agent Performance Dashboard

Short Description / Purpose –
A Power BI dashboard designed to provide a holistic overview of property listings, sales performance, and agent contributions within the real estate market. The dashboard visualizes live property data—covering listings, sales, and pending deals—while tracking market status by type, price trends, and agent performance. The goal was to enable data-driven decision-making for property agencies, helping them monitor inventory, identify trends, and optimize sales strategy.

Data Source –

Source: Real estate property dataset (CSV/Excel)

Included Fields: MLS ID, Address, City, Area (sqft), Lot Size, Price, Property Status (For Sale, Sold, Pending), and Agent details

Total Properties: 3,000 entries across multiple cities

Updated monthly from the agency’s property management system

Tech Stack –

a. Power BI Desktop

Built KPI cards for total listings: For Sale, Sold, Pending, and Total Properties

Created interactive charts showing days-on-market and price trends

Designed Property Market Status by Type visual to compare segments (Apartment, Townhouse, Single Family, etc.)

Used DAX measures for calculating sales percentages, pending ratios, and property type distributions

b. Power Query (ETL)

Cleaned and standardized location, size, and pricing data

Derived calculated columns for area, lot size grouping, and property status categorization

c. Excel (Data Preparation)

Initial dataset transformation and missing value imputation

Ensured consistency in city and agent name mapping

Key Features / Visuals –

a. KPI Cards

For Sale, Sold, Pending, and Total Properties

Dynamic percentage completion for each category

b. Days Breakdown of Property Status & Price Trends

Dual-axis chart combining bar (property count) and line (average price)

Trendlines showing performance over time windows (0–30 days, 30–60 days, 61–90 days, over 90 days)

c. Agent Performance Summary

Top 5 performing agents listed by total sales and active listings

Enables comparison of productivity across agencies (Compass, RE/MAX, Coldwell Banker, etc.)

d. Property Market Status by Type

Category-level breakdown (Apartment, Condo, Townhouse, Multi-Family, Single Family)

Visualized property availability and demand patterns

e. Interactive Property Table

Searchable table with MLS ID, Address, City, Area, Price, and Status

Linked to chart filters for drill-through analytics

f. 3D Property Visual

Incorporated modern house visualization for presentation aesthetics and stakeholder engagement

Business Impact / Insights –

a. Inventory Optimization –
Revealed the ratio of sold-to-pending listings, helping agencies adjust pricing and marketing for overstocked areas.

b. Agent Benchmarking –
Enabled management to compare agent performance, identify top closers, and realign resources.

c. Market Trend Identification –
Showed price movement trends by property type and city, guiding strategic decisions on where to invest or advertise.

d. Sales Efficiency Monitoring –
Tracked how long properties stayed on the market and correlated pricing with speed of sale.
